# Decisions

One file per decision, `YYYY-MM-DD-<slug>.md`, in this shape:

```markdown
# <Decision title>

Decided <YYYY-MM-DD>. Scope: <always or area>. Status: <active or superseded by <file>>.

**Decision:** ...

**Why:** ...

**How to apply:** ...
```

Areas are listed in [AGENTS.md](../../AGENTS.md#decisions). Superseded decisions keep their file, marked as such, and drop off this list.
