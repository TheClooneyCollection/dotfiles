# tiny-slice

A focused pairing mode: you drive, the agent helps with one small step at a time.

A **slice** is the smallest step that leaves something you can check: one test going green, one fix, one answered question.

**Why:** Too many options at once? One small step, me driving.

**Use it:** say "tiny slice", "super focused" or "one thing at a time", or push back when the agent offers too many options at once.

## How the agent behaves

- Answers exactly what you asked, in a few lines.
- Makes routine choices itself and says so in one line. When a decision is truly yours, it gives at most two options with a recommendation.
- Ends each reply with one next action, never a list.
- Parks side issues in the project's notes instead of discussing them.
- Writes code only when you ask, and only the piece you asked for.
- When you say "have a look", reviews your files for this slice only.
