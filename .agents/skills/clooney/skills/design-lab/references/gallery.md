# Gallery page for a round

One static HTML page per round, generated by a small script so it can be rebuilt after each verdict.

- **Top box, "Changed for every item":** shared changes in this round (e.g. sticky nav, tag style), so they are not repeated per card.
- **"To pick / review" section first:** each open decision as a group, the variants side by side (e.g. r2 vs r3, contrast A/B/C, palette options), each with its badge. Close a group by changing badges (Picked / Not picked), not by deleting it, until the round is over.
- **"All items" grid:** one card per item:
  - preview screenshot (click opens the mockup);
  - a short, stable ID derived from an author or round prefix plus the file name without its extension (e.g. `r2-paper`), unique within the round and easy to type on a phone; show it as a small monospace chip under the full-size item, with a **Copy ID** button so the user can paste it into feedback. Copy the ID to the clipboard; if clipboard access fails or is unavailable, select the ID text and show "Selected, copy it". Feed or thumbnail repeats refer to the same ID, never get a separate one;
  - verdict badge and supported schemes ("Light + dark", "Dark only");
  - "Changed since your review" list, three to five short lines;
  - links to every page of the mockup (home, post, list pages, a translated page if the project has one).
- **Round landing page:** list every item with its ID and a link to it, so one page covers the whole round; the gallery can serve as this page.
- **"Dropped" section last,** dimmed, so dropped work is still findable.
- **Screenshots:** headless Chrome at 1440 and 390 wide, light (`--blink-settings=preferredColorScheme=1`) and dark (`--blink-settings=preferredColorScheme=0`), each run with its own `--user-data-dir`. These flags override the machine's appearance; `--force-dark-mode` does not switch `prefers-color-scheme`, it only looked right on a Mac in Dark mode. Name them `<round>-<page>-<scheme>-<width>.png` so the generator can pick the newest round.
- **Phone layout:** cards in one column below ~420px, images `width:100%`, no fixed widths, long words wrap.
- **Keep the old gallery** when restructuring: rename it (e.g. `revisions-detail.html`) and link it from the new one.
