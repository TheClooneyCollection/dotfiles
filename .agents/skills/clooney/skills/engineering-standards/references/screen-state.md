# Screen state and presentation

Derive presentation from raw state, keep formatting at the view and guard async actions.

13. **Store raw, derive the rest.** The view model stores only what the user did and what was loaded (the to-do items, the chosen filter, the typed search text); the visible list, the counts and every view state are computed, never stored and synchronised. Swift: computed properties on the `@Observable` view model.
14. **Formatting context belongs to the view.** Locale, time zone and units are the view's business. View states hold domain values and expose `text(locale:)`; the view passes its environment's locale; formatters take it as a parameter; view models never hold one. Tests pass a fixed locale, never the current one. Swift: `@Environment(\.locale)` in the view, `Locale(identifier: "en_US")` in tests, no `Locale.current` below the view.
15. **Guard re-entry before the first await.** An async action checks and sets its state before suspending, so a second call (a sign-up button tapped twice) is dropped, not debounced, and two requests never run at once. Test it with a request held open: the second call returns at once and one request is counted. Swift: `guard case .idle = state else { return }` then `state = .submitting` before the `await`; a `CheckedContinuation` holds the fake open in the test.
16. **Components take plain inputs and closures.** A reusable component takes strings, booleans or a view state plus `onX` closures; it never takes the view model or a binding to its types. Only the screen view knows the view model. Swift: `TodoRow(title: String, isDone: Bool, onToggle: () -> Void)`.
17. **One use stays private; a second use earns a type.** A helper used once is a private extension at the bottom of its caller's file; a view part becomes its own component only when a second place uses it.
18. **Every escape hatch carries its reason.** A lint suppression, a force unwrap, a deliberate crash and a limit exception each get a one-line comment saying why it can't fail or why the limit is wrong here. Numbers tuned together sit in one place. Swift: `// Fixed values in range, so it can't throw.` above `try!`; `swiftlint:disable:next` with the why; one `enum` holding every animation duration.
