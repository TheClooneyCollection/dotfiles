# Structure and dependencies

Separate responsibilities and make dependencies, concurrency and domain boundaries explicit.

6. **View model or view state, by one test.** If it changes something, awaits or holds a dependency, it's a view model. If the same input always gives the same output, it's a view state: data plus pure methods. The view model builds the view states; the view only renders them. Swift: `@Observable @MainActor final class TodoListViewModel` builds `nonisolated struct TodoRowState: Equatable`.
7. **Inject capabilities, not logic.** A capability is one function type (`fetchForecast`, `saveItems`); a `Dependencies` record groups them and makes no choices; a consumer takes only the functions it uses, not the record. An interface only when several operations are always swapped together and a second real implementation exists. Conversion, rounding, formatting and sanitising are plain functions, never injected: there is nothing to swap. Swift: `typealias FetchForecast = @Sendable (City) async throws -> Forecast`; a `static func` for the pure part.
8. **Configuration is what deploys change; paths are code.** Base URL, API version and keys live in a configuration value passed inward; endpoint paths and query names are private constants in the endpoint builder. Tests pass `https://example.com` to prove nothing is hard-coded. Swift: `struct APIConfiguration { let baseURL: URL }`; `private enum Path { static let forecast = "v1/forecast" }`.
9. **Say the concurrency contract out loud.** A type that crosses a thread, task or callback boundary declares that it is safe to, even where the compiler would infer it, so an unsafe field fails at the definition rather than at a distant use. Keep the toolchain's defaults until profiling asks for more. Swift: with main-actor default isolation, write `nonisolated` and `: Sendable` on every such type and on its extensions too (nested types and extensions don't inherit it); no `@concurrent` until profiling asks.
10. **Each layer owns its failures, typed.** The client normalises transport, status and decode failures into its own error; the repository decides policy (drop a malformed item, fall back to cached data); the view model collapses the outcome into a state case. Swift: a nested `enum Error: Swift.Error`, functions `throws(Error)`, cases payload-free until something needs the payload so they stay `Equatable` for `#expect(throws:)`.
11. **Validate where the value is made, then trust it.** A domain initialiser checks ranges (an age of 13 to 120 on a sign-up form); decoding routes through that initialiser, since a synthesised decoder skips it; mappers reject instead of coerce. No re-checks downstream. A separate wire type is optional when the wire shape matches the model one to one and decoding still runs the validating initialiser. Swift: a custom `init(from decoder:)` that calls the throwing `init`; a whole-match regex before `Decimal(string:)`, which reads `"12abc"` as 12.
12. **Precision-bearing values use a decimal type, parsed from strings.** Money is the common case. A price, a dose, a measured weight: anything a user types or a server sends as a string to protect precision. Wire types carry the string; user text is parsed with its locale; the domain holds a decimal, never a binary float; rounding is one explicit domain operation with a named mode. Swift: `Decimal`, `Decimal(string:)`, one `rounded(decimals:mode:)` helper.
