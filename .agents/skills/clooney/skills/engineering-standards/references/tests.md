# Tests

Test shape, doubles, factories and fixtures are in the [behavior-tests](../../behavior-tests/SKILL.md) skill; this file adds only what that skill leaves open.

24. **Fake the world, keep your own layers real.** A fake stands in for something outside the app (the network as a URL-to-fixture table), and the decoder, mapper and repository above it run for real. At a unit's own injected functions, canned values are allowed and encouraged: a view model test supplies the capability directly instead of going through the real repository. Nothing is replaced by a mock that records calls, and a call is asserted only when the call itself is the behaviour. Swift: a view model test passes `fetchForecast: { _ in .sample }`; an integration flow uses a `[URL: Data]` router returning data plus `HTTPURLResponse`; `confirmation` only for "exactly one request".
25. **Fixtures carry their origin.** A raw fixture says which call produced it and when it was checked, so a stale one is visible. Swift: a doc comment on each JSON fixture.
26. **A bad test input stops the test.** A test input that fails to build stops the test with a message rather than silently shrinking the data set. Swift: `try #require(...)` per element, not `compactMap`.
27. **The ordinary suite is offline and shows every state.** Tests that hit a live service sit behind an opt-in switch. Snapshot tests render each screen state in each supported locale and at the largest text size; an animated element gets a narrow tolerance with the reason beside it. Input to output rules are tables. An open decision is a disabled test with the reason, not a deleted one. Swift: `@Suite(.enabled(if: liveTestsEnabled))` on an environment variable, `@Test(arguments:)` tuples, `.disabled("Undecided: …")`.
28. **Assert the final wire output.** Serialization tests check the request representation, not the choreography of internal conversion helpers. Swift: encode the actual request DTO and assert its supported string, array and number forms and explicit JSON `null` (distinct from an omitted key).
