# Skills

- **The description is the trigger,** loaded every turn: what it does, then one trigger per distinct case, including the user's own phrases in their language. No synonyms.
- **Minimal core.** SKILL.md holds only what is needed every time the skill runs. Put anything else in a reference file linked from SKILL.md, named in the step that needs it.
- **Each step ends on a checkable done:** "every finding verified", not "understand the code".
