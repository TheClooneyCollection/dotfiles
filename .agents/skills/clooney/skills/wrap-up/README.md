# wrap-up

Before you clear or end a session, the agent lists what is worth saving and what is unfinished, so nothing learned gets lost.

**Why:** Worried about losing the lessons a session taught? No more! This lists what to save and what is unfinished before I clear.

**Use it:** say you are about to clear, reset or end the session.

## What you get

- **Lessons not yet written down:** your corrections, gotchas, decisions and workflows explained only in chat. Each comes with a proposed home (an `AGENTS.md` rule, a doc, a skill or memory) and the exact wording.
- **What it would skip,** with reasons, so you can overrule.
- **Numbered choices:** completed work worth recording, unfinished work you could continue, and live state needing attention, including running agents or jobs, worktrees and uncommitted or unpushed changes. Choose what to save, continue or drop; unselected work stays pending.

It changes nothing until you pick. Afterward, approved notes go to their agreed homes and anything needed across a clear goes into a local, uncommitted `HANDOFF.md`. Existing content is preserved; entries are removed only when completed, dropped or saved to an approved persistent record, and the empty handoff is deleted.

Agent instructions: [SKILL.md](SKILL.md).
