# wrap-up

Before you clear or end a session, the agent lists what is worth saving and what is unfinished, so nothing learned gets lost.

**Why:** Worried about losing the lessons a session taught? No more! This lists what to save and what is unfinished before I clear.

**Use it:** say you are about to clear, reset or end the session.

## What you get

- **Lessons not yet written down:** your corrections, gotchas, decisions and workflows explained only in chat. Each comes with a proposed home (an `AGENTS.md` rule, a doc, a skill or memory) and the exact wording.
- **What it would skip,** with reasons, so you can overrule.
- **Unfinished work:** running agents or jobs, worktrees, uncommitted or unpushed changes, questions you have not answered.

It changes nothing until you pick.

Agent instructions: [SKILL.md](SKILL.md).
